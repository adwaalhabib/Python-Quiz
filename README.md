# IT Knowledge Quiz

## About

This is a simple Python project that asks the user basic IT questions and gives a score at the end.

## What It Does

- Asks for the student's name
- Shows IT questions
- Gives multiple answer choices
- Checks the answers
- Calculates the score
- Shows the percentage

## How to Run

1. Open the `knowledge_quiz.py` file.
2. Run it using Python.
3. Enter your name.
4. Answer the questions.
